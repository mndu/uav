# Universal Activation Verbalizer — EMNLP 2026 project page

Website: https://mndu.github.io/uav/

A static research page using the same layout as the SAEExplainer project page: centered paper metadata, bracketed links, the algorithm framework before Overview, and white panels for Overview, Results, and BibTeX.

Results retain two comparisons from the supplied paper: overall scores against baselines from Table 2 and a fact-retrieval qualitative example from Table 19. All displayed values and author details were checked against `1341_Universal_Activation_Verb.pdf`.

Open `index.html` locally to preview. No build process is required.
